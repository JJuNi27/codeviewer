# Code Visualizer (Python)

## 📌 프로젝트 개요
이 프로젝트는 **파이썬 코드를 글 설명이 아닌 시각화(표, 도형 등)** 로 이해할 수 있도록 돕는  
VS Code 확장 프로그램입니다.

코딩 초보자가 `for`, 중첩 반복문, 2차원 배열 같은 개념을  
머릿속으로 상상하지 않아도 **구조를 눈으로 바로 이해**할 수 있게 만드는 것이 목적입니다.

---

## 🎯 개발 목적
- 파이썬 문법을 **실행 결과가 아니라 구조 관점**에서 이해할 수 있도록 돕기
- 글 설명 위주의 기존 학습 방식에서 벗어나  
  **표(Table), 도형(Flowchart), 격자(Grid)** 기반 시각화 제공
- 코드를 작성하는 즉시 시각화가 반영되는 **실시간 사고 보조 도구** 만들기

---

## 🛠 현재 구현된 기능 (MVP)
📅 개발 기준일: **2025-02-23**

- VS Code Extension 기본 구조 구성
- 코드 타이핑 시 **실시간 WebView 업데이트**
- `for` / 중첩 `for` 구조 분석 (라이트 버전)
- 반복문 구조를 **표(Table)** 로 시각화
  - 반복 단계
  - 루프 변수
  - 반복 범위
  - 역할 추정 (행 / 열)
- 반복 흐름을 **도형(Flowchart, SVG)** 으로 시각화
  - 반복 구조
  - body 블록
  - 반복 화살표 표현

---

## 🧠 현재 설계 방향
- 코드 실행 ❌
- 문법 구조 분석 ⭕
- 설명 텍스트 최소화
- **시각 요소 중심 설계**

> “이 코드가 어떻게 동작하는지”가 아니라  
> “이 코드의 구조가 어떻게 생겼는지”를 보여주는 데 집중합니다.
